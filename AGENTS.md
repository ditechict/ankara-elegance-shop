## Agent handoff

Before making any change, read [`AGENT_HANDOFF.md`](./AGENT_HANDOFF.md). It carries
the stack rules, security invariants, payment-webhook contract, brand/UI standard,
current project state, and the ordered task list for continuing this build. The
archived plans in `.lovable/plan/` are the specification behind it.
